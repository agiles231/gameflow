# Export and delivery fixtures

Record original source identity, integration-copy identity, selected objects, exporter/version, supported format, unit/axis/pivot transforms, material/texture dependencies and destination. Discover exporter support rather than assuming a format exists. Export only owned objects and confirm output is accessible to the importing host.

For ordinary Meshy delivery, check readable files, required dependencies and successful intended Unreal import/loading. Do not launch geometry measurements, visual quality comparisons, numerical sweeps or creative repair. Keep pipeline qualification distinct from production asset acceptance.

Qualify a newly connected Blender route in an isolated disposable file or an explicitly assigned clean testing session. An unrelated dirty production scene is not a test fixture. Use one explicitly authorized simple primitive to exercise create/save/export/reopen and a safe missing-object query. No rigs or animation fixtures. Record actual tool names, file identities, successful/failed stages and unavailable checks. Only test Unreal import in an assigned disposable project.

Release session ownership and retain a concise report. Remove only owned disposable artifacts when appropriate. Schema inspection or simulated routing is not live integration coverage; a successful Blender export is not proof of Unreal import.
