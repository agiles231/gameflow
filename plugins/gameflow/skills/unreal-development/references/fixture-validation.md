# Disposable integration validation

Use a disposable Unreal project/editor explicitly assigned to testing. If only a production editor is connected, perform read-only discovery and report live mutation checks as unavailable. Preserve unknown dirty work and coordinate exclusive editor access.

Record project identity, engine version, exposed tool schema and Windows/WSL mapping. In a unique fixture-owned folder, import one known static mesh or create an explicitly allowed simple primitive through supported tools. Inspect/save/reopen it and confirm persistence. Exercise only the feature being qualified, such as a material parameter read or a named automation test with actual result counts. Use a safe missing-asset query to check bounded failure. No rigs or animation fixtures.

Record tools, artifact identity and expected/observed results. Distinguish live passed, failed, simulated only, and unavailable coverage. Do not generalize static import support into other capabilities. Restore owned session changes where safe and release the editor. Remove only owned disposable artifacts when appropriate; preserve the concise report.
